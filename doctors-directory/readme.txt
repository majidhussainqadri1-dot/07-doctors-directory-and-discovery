Canonical verified-doctor public projection, search, filtering, ranking, moderation, SEO, privacy and operational controls for the Sabri Social Homeopathy Platform.

== Description ==

File 07 owns only the publicly searchable projection of eligible verified doctors, directory filters and cursor pagination, Founder/featured/recent/all sections, public-safe discovery orchestration, safe public SEO, listing reports, private discovery preferences, reconciliation and operational controls.

Identity, membership, doctor verification evidence and decisions, professional profile truth, clinic/availability truth, notifications, application shell, visual system, global merit ranking and security assurance remain with their canonical platform modules.

Highlights:
* Fail-closed multi-owner eligibility projection.
* Separate official Founder section; Founder never appears in ordinary or recent groups.
* Time-bounded, labeled and audited featured doctors with no paid boost.
* Top 10 / Top 100 / Top 1000 / All Verified integration through File 26; no fabricated ranked tiers.
* Dedicated indexed projection table and stable signed cursor pagination.
* Safe alias/transliteration-aware search and allowlisted facets.
* Country, city, specialty, language, qualification, experience, consultation mode, accepting-patient, currency and fee filters.
* Doctor comparison, guided finder, privacy-safe nearby search, map/list view and local-time availability.
* Country coverage, advanced professional/accessibility filters and public knowledge-footprint projections through owner adapters.
* Saved searches with File 19 notification handoff and private doctor shortlists.
* Why-this-doctor explanations, personal display ordering explicitly separated from official global merit ranking, and ranking transparency.
* Natural-language multilingual discovery parsing, zero-result recovery and emergency-query safety diversion.
* Anti-gaming discovery-integrity contract, privacy-safe unmet-demand aggregates and low-bandwidth offline packs.
* Versioned contract filters for Files 00, 03, 08, 09, 19, 24 and 26.
* Idempotent inbox/outbox events, retries, dead-letter state and scheduled reconciliation.
* Doctor-owned directory status and discoverability consent.
* Report moderation with optimistic concurrency and atomic audit transitions.
* WordPress privacy export/erasure coverage for directory state, saves, reports, saved searches and shortlists.
* Canonical routes, structured data, public sitemap, noindex filtered variants and private no-cache status page.
* Safe Mode, System Check, redacted health evidence and bounded repair operations.
* Green primary identity, WCAG-oriented focus, contrast, 44px targets, responsive and RTL-ready interface.

== Installation ==

1. Install the exact approved File 00, File 03 and File 09 packages. File 08 is required for live clinic geo/availability enhancements; File 19, 24 and 26 enhance alerts, assurance and official ranking.
2. Upload the deterministic release ZIP on Hostinger staging.
3. Activate the plugin and run Doctors Directory > System Check.
4. Run bounded reconciliation until next_cursor is zero.
5. Exercise the 24 future-discovery journeys with real companion providers on staging.
6. Complete the staging acceptance matrix in docs/STAGING-ACCEPTANCE.md.
7. Obtain explicit Founder acceptance before production deployment.

== Safety and trust ==

Verification is not an endorsement, cure claim or treatment guarantee. Emergency care is outside this directory. Emergency-type natural-language queries suppress directory recommendations and show an urgent-care diversion. Public fields are allowlisted and must be consented. Private identity evidence, patient data and internal risk details are never indexed or exposed. Precise user coordinates are request-scoped and not persisted by the future-discovery layer.
