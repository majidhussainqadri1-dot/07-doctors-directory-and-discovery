An American English verified-doctor directory and discovery layer for the Sabri Social Homeopathy Platform.

== Description ==

File 07 builds the first 25 percent of the public Doctors directory.

Features:
* Public browsing without registration.
* Verified doctors only in public search.
* Search by name, specialty, country, city, language, qualification, experience, and consultation method.
* Founder, featured, recently joined, and all-doctors sections.
* Professional cards with verification, profile completion, contributions, phone, and WhatsApp controls.
* Extended professional profiles and directory settings.
* Founder profile fixed at 100 percent completion.
* Administrative featured and visibility controls.
* Logged-in profile reporting and moderation.
* WordPress privacy export and erase callbacks.
* ProfilePage and Person structured data for public verified profiles.
* Bright light orange responsive interface.

== Requirements ==

File 03 — Sabri Profiles and Doctors must be installed and active. Files 01 through 06 should remain active for complete platform integration.

== Installation ==

1. Upload the ZIP through WordPress Admin > Plugins > Add New > Upload Plugin.
2. Activate Doctors Directory and Discovery.
3. Open the public Doctors page.
4. Review directory settings on a doctor account.
5. Use Doctors Management for featured placement, visibility, and reports.

== Safety and trust ==

Directory verification is not an endorsement or treatment guarantee. Users should confirm professional licensing and suitability in their location. The plugin does not add ratings, automated medical rankings, cure claims, or public identity documents.
