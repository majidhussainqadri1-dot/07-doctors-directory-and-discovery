# Mandatory Post-Upload Review

This baseline import is an evidentiary checkpoint, not a completion declaration.

Before any release or next-stage development, review File 07 against the governing master plan and verify at minimum:

1. File 03 dependency handling and failure behavior.
2. Public listing of verified doctors only.
3. Founder, featured, recently joined, and all-doctors sections.
4. Search filters: name, specialty, country, city, language, qualification, experience, and consultation method.
5. Profile completion, phone, WhatsApp, internal-routing boundaries, and visibility consent.
6. Administrative featured/visibility controls and report moderation.
7. Privacy exporter/eraser correctness and absence of private identity-document exposure.
8. Structured data accuracy and no false endorsement or treatment-guarantee implication.
9. Security review: capabilities, nonces, sanitization, escaping, prepared SQL, ownership checks, rate limits, and safe redirects.
10. Fresh install, upgrade, deactivation, uninstall, rollback, staging, responsive, accessibility, and cross-browser acceptance.

All discovered defects must be corrected and re-tested before approval.
